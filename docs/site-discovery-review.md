# サイトの見つけやすさ・回遊改善（2026-10-24）

## 調査と判断

比較対象はウォーカープラスとじゃらんnetのイベント入口。ウォーカープラスの公式媒体案内は月間平均146,420,000PV・18,460,000UU（2024年4～11月の集計）を掲載している。現在の実測値や、個々のUIがアクセス増加を生んだ因果関係を示す数値ではない。

| 観察した特徴 | 神楽めぐりの現状 | 今回の対応 |
| --- | --- | --- |
| ウォーカープラスは日付・地域からすぐ探せる | 今週末・今月の入口が大きな画像の下にある | 入口を画像より前へ移動し、日付・地域検索を追加 |
| じゃらんはエリア別一覧へ直接進める | 都道府県リンクがページ下部にある | 掲載のある県への通常リンクを上部にも配置 |
| 両サイトは日程・場所を一覧で示す | 既に日時・会場・料金・詳細ページがある | 既存表示を維持 |
| Googleは分かりやすい構成とクロール可能なリンクを推奨 | 静的ページ・canonical・sitemap・Event構造化データは既存実装 | 既存の県別URLを再利用し、重複ページを作らない |

注釈は専用のannotationクラスで0.85rem（標準16px設定で13.6px）、行高1.8とした。出典・自動取得説明・概略位置の注意・広告注記が対象。日時・会場・料金・ボタンおよびプライバシーポリシー本文は小さくしない。色のコントラストとブラウザ拡大を維持する。
