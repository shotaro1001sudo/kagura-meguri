# NoLang 向けのプロンプト(神楽・演目の解説ショート動画)

Instagram リール・YouTube ショート用に、NoLang で神楽の解説動画を作るときのプロンプトです。
事実は data/kagura-info.json の本文(出典つき)だけを使います。NoLang に調べさせたり、話を足させたりしません。

## 使い方

1. 下の「型A(神楽の紹介)」か「型B(演目の紹介)」をコピーする。
2. `{{ }}` の所を、data/kagura-info.json の該当する神楽の文章で埋める(言い換えずに貼る)。
3. NoLang に貼って生成する。
4. 「投稿前の確認」を見てから投稿する。

## 型A:神楽の紹介(45〜60秒)

```
あなたは、日本の伝統芸能「神楽」を紹介するショート動画の構成作家です。
下の【資料】だけを使って、縦型(9:16)、45〜60秒の解説動画を作ってください。

# 守ること
- 事実は【資料】に書いてあることだけ。年代・数字・地名・演目名・文化財の指定を、資料にない形で足したり言い換えたりしない。
- 「日本一」「最古」「必ず」など、資料にない強い言い切りをしない。
- 映像で、神楽の舞い手・面・衣装・大蛇を、本物らしく描いた絵や写真にしない(実物と違う姿を見せないため)。背景は和紙・和柄・夜の神社の灯りのような抽象的なものと、大きな文字で見せる。
- 読み上げは、やさしい話し言葉で300字前後。1文は短く。専門用語には一言の説明をつける。
- 画面の文字は、読み上げの要点を1画面15字以内で。

# 構成
1. つかみ(〜3秒):【一言紹介】をもとに、問いかけの1文。
2. どんな神楽か(〜15秒):【概要】の要点。
3. 見どころ3つ(〜30秒):【特徴】と【主な演目】から3つ選び、1つ1〜2文。
4. 観るときのコツ(〜8秒):【観賞のコツ】から1つ。
5. しめ(〜4秒):「開催予定は『神楽めぐり』で探せます」と言い、画面に kagurameguri.jp を出す。

# 資料(出典:{{source}})
【神楽の名前】{{神楽名}}
【一言紹介】{{tagline}}
【概要】{{intro}}
【歴史】{{history}}
【特徴】{{features}}
【主な演目】{{programs(演目名:説明)}}
【観賞のコツ】{{viewing}}
```

## 型B:演目の紹介(30〜45秒)

```
あなたは、日本の伝統芸能「神楽」を紹介するショート動画の構成作家です。
下の【資料】だけを使って、{{神楽名}}の演目「{{演目名}}」を紹介する、縦型(9:16)、30〜45秒の動画を作ってください。

# 守ること
- 事実は【資料】に書いてあることだけ。あらすじ・登場する神・場面を、資料にない形で足さない。
- 映像で、舞い手・面・衣装・大蛇などを本物らしく描かない。背景は抽象的な和の素材と大きな文字にする。
- 読み上げは、やさしい話し言葉で200字前後。

# 構成
1. つかみ(〜3秒):演目の一番の見どころを問いかけにする。
2. どんな演目か(〜20秒):【演目の説明】を、やさしく言い直す。
3. どの神楽の演目か(〜10秒):【神楽の一言紹介】で、どこのどんな神楽かを一言。
4. しめ(〜4秒):「開催予定は『神楽めぐり』で探せます」と言い、画面に kagurameguri.jp を出す。

# 資料(出典:{{source}})
【神楽の名前】{{神楽名}}
【神楽の一言紹介】{{tagline}}
【演目名】{{演目名}}
【演目の説明】{{programs の text}}
【観賞のコツ】{{viewing}}
```

## 埋めた例:石見神楽(型A)

```
あなたは、日本の伝統芸能「神楽」を紹介するショート動画の構成作家です。
下の【資料】だけを使って、縦型(9:16)、45〜60秒の解説動画を作ってください。

# 資料(出典:浜田市観光協会(石見神楽公式サイト)「石見神楽とは」)
【神楽の名前】石見神楽
【一言紹介】島根県西部 ・ テンポの速い「八調子」と、金糸・銀糸の豪華な衣装
【概要】島根県西部、石見地方を代表する伝統芸能です。古事記や日本書紀の神話を題材に、大太鼓・小太鼓・手拍子・笛の囃子にのって、金糸・銀糸をあしらった豪華な衣装で舞います。秋祭りの夜には、あちこちの神社から神楽囃子が聞こえてきます。
【歴史】
- 起源には諸説ありますが、室町時代の後期にはすでに演じられていたとされます。
- 明治の初めから、氏子(地域の人たち)が舞い手を務めるようになりました。テンポの速い「八調子」が取り入れられたのもこの頃です。
- 2019年に、石見神楽と15の構成文化財が日本遺産に認定されました。
【特徴】
- テンポによって「六調子」と「八調子」に分かれます。いまの主流は、速く激しい拍子の八調子です。
- 囃子は大太鼓・小太鼓・手打鉦・横笛。楽譜はなく、大太鼓の奏者が舞い手の動きを見ながら全体を引っぱります。
- 衣装は金糸・銀糸をふんだんに使った豪華なもの。面は、地元特産の石州和紙でつくる張子面です。
- 大蛇の胴は、石州和紙と竹でつくる軽い蛇腹式。戦後は、何頭もの大蛇が登場する舞台も増えました。
【主な演目】
- 大蛇:スサノオノミコトが八岐大蛇を退治する、石見神楽の花形。多くの公演で最後を飾ります。
- 岩戸:天岩戸の神話をもとにした演目。岩戸が開いたあとは、面を外して喜びの舞を舞います。
- 恵比須:恵比須様が鯛を釣る舞。客席に餅や菓子をまく場面があり、子どもたちに人気です。
【観賞のコツ】
- 初めてなら、「大蛇」が上演される日を選ぶのがおすすめです。
- 囃子が速いので、大太鼓と舞い手の動きをあわせて見ると、いっそう楽しめます。
```

## 投稿前の確認(人が見る)

- 読み上げと字幕に、資料にない事実(年代・指定・「日本一」など)が入っていないか。
- 映像に、AI が描いた舞い手・面・大蛇が出ていないか。出ていたら、その場面の素材を差し替える。
- 神楽の名前・演目名・地名の読み上げが正しいか(例:石州=せきしゅう、八岐大蛇=やまたのおろち)。違えば、読みをひらがなにして作り直す。
- 投稿の説明文に、出典(例:「出典:浜田市観光協会『石見神楽とは』」)と、NoLang の素材で求められるクレジットを入れたか。
- 投稿の説明文に、その神楽のページの URL(kagurameguri.jp の種類のページ)を入れたか。

## 注意

- 文化財の指定は、取り違えやすい所です(石見神楽で国の重要無形民俗文化財なのは、源流の「大元神楽」)。指定に触れるときは、資料の文をそのまま使います。
- 写真を使うときは、許可を得たものだけにします。
