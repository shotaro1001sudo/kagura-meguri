# 公演カードの写真対応

2026-11-05: 実写真の掲載はゼロ。既存素材はロゴ・ヒーロー・OGなどで、公演写真として利用許諾を確認できる素材はない。これらを公演写真に転用しない。

公演一覧は日付の小さな面を目印にし、写真がない場合は空の写真枠を作らない。トップ・県・種類・月・今週末・定期公演・日付検索で写真対応を共通化。検索条件、日付順、会場・料金・予約情報、無料掲載は維持する。

## 現在の公開制限

`data/performance-photos.json` は `publicationEnabled: false`、`photos: []`。無効のまま写真を登録するとビルドを止める。主催者案内・免責事項・投稿条件の「写真を掲載・転載しない」という現行方針は変更していない。写真募集や外部連絡も行わない。

実写真を公開する前には、運営者が掲載方針を決定し、既存の主催者案内と規約等との整合を承認のうえ見直す必要がある。この実装は、その変更や写真公開の承認を代行しない。

## 後日、掲載が承認された場合

収集・投稿データに画像URLを追加しても公開されない。編集者が独立した台帳に登録する。

- `kind`: `events` または `regular`。`id`: 対応する実在の公開公演ID。
- `file`: `assets/performance-photos/` 内の小文字英数字とハイフンの WebP 名。実ファイルが必要。外部画像URL・パストラバーサル・ディレクトリ外へのシンボリックリンクは不可。
- `width` / `height`: 書き出した画像の実寸。横320〜1200・縦200〜1200、100KB以下。撮影対象・掲載場所に適したサイズで圧縮する。
- `alt`: 写真の内容を説明。`caption`: 撮影された公演・年など、今回の開催を撮ったと誤解させない説明。
- `credit`: 権利者指定の表記。`sourceUrl`: 出典のHTTPS URL。
- `permission`: 公開してよい利用条件の短い説明。`permissionUrl`: 公開可能な許諾・利用条件の根拠URL。私的なメールや個人情報を含む証拠は登録しない。
- `rightsConfirmed: true` / `checkedAt: YYYY-MM-DD`: 編集者の権利確認。掲載・複製・サイズ変更・広告のあるサイトでの使用、必要な肖像等の許可を含めて確認する。公式サイトにあるだけで転載可とは扱わない。

台帳の文字列が埋まっていても法的な許可の実在は自動判定できない。人による出典と条件の照合が必須。承認後に `publicationEnabled` を有効にする。許諾が切れた場合は台帳から外し、再ビルドする。

表示は同一サイト内の画像だけ。遅延読み込み、非同期デコード、寸法指定、全体が見える縮小を使う。クレジットと根拠リンクを画像下に置く。画像読み込み失敗時は枠ごと隠して文字カードに戻す。新規外部サービスやCookieは追加しない。

## 検証

- `npm test`: 権利情報欠落、公開停止、URL/パス、日付、重複ID、altエスケープ、静的・動的画像失敗、隔離した写真有効ビルド、既存の全回帰。
- `npm run build` / `git diff --check` / 変更したJSの `node --check`。
- `node tests/performance-cards-browser.mjs`: Chromiumで1280/390/320px、ライト/ダーク、トップ・日付検索・広島県・週末を表示。横溢れ、都道府県絞り込み、検索0件、写真読み込みと失敗を確認。
- ブラウザ試験の単色WebPは試験専用。実写・神楽の画像として公開せず、配信ファイルにもコピーしない。
