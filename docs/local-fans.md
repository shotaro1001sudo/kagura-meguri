# 地元の神楽ファン向けの集客(広島から)

方針(2026-11-06 決定): **地元・近県の神楽ファン**に、くり返し使ってもらう。最初は**広島(広島神楽)**に力を入れる。
神楽団・主催者とはやりとりせず、**公開されている情報**と、自分の SNS で進める。費用はかけない。作業は週3時間ほど。

地元のファンは、すでに NPO 広島神楽芸術研究所の神楽日程表などで日程を見ている可能性が高い。
そこにない「**神楽団・演目で探せる**」「**自分のカレンダーに届く**」「**SNS で広めやすい**」を、このサイトの強みにする。

## サイトの仕組み

| 仕組み | URL | 中身 |
|---|---|---|
| 神楽団ページ | `/troupe/津浪神楽団.html` ほか・一覧 `/troupe/` | その団体の出演予定(演目・共演)と、これまでの出演 |
| 演目ページ | `/program/八岐大蛇.html` ほか・一覧 `/program/` | その演目が観られる公演と出演団体。表記の違い(瀧夜叉姫・大蛇など)は1ページにまとめる |
| 開催ページの「出演」 | 各 `/events/*.html` | 要点の表に出演・演目(神楽団・演目ページへのリンク)。構造化データの performer |
| 県ごとのカレンダー | `/ics/hiroshima.ics` など(県のページに登録ボタン) | その県の開催予定と、毎週の定期公演の90日先までの公演日。毎日の公演は入れない |
| 今週末の広島の神楽 | `/weekend/hiroshima.html` | 広島県の今週末の公演と、SNS 用の画像(縦1080×1350)・X と Instagram の投稿の文 |

- 出演・演目は、開催データの `lineup` に入れる(下の「毎週の作業」)。**開催予定のある**神楽団・演目のページだけを、検索とサイトマップに出す。これまでの出演だけのページは `noindex` で残す。
- 県ごとの今週末を作る県は、`config.json` の `weekendPrefectures`(いまは `["広島県"]`)。足せば、その県のページと画像もできる。
- SNS 用の画像は、ページを開いたブラウザの中で描く(GitHub の環境には、画像を描くブラウザがないため)。「画像を保存」で PNG を保存。スマホで共有の画面が使えるときは「共有する」も出る。

## 毎週の作業(目安: 週3時間)

### 1. 出演・演目を入れる(1.5時間)

1. 広島の公演の、公式の日程・チラシ・観光協会のページで、**出演する神楽団と演目が発表されているか**を見る。
2. 管理者用ページの「開催一覧」で、その公演の「編集」を開き、**出演・演目**の欄に、1行に1団体で書く。
   ```
   津浪神楽団: 八岐大蛇、紅葉狩
   横田神楽団
   ```
   - 演目が未発表なら、団体名だけ。演目の「」は付けても外しても同じ。
   - 一部の団体しか分からないときは、「ほかにも出演がある」に印を付ける(「ほか」と表示)。
   - 名前は**公式の表記のまま**(「神楽團」を「神楽団」に直さない)。
3. 保存すると、そのまま公開される(数分後に、神楽団・演目のページも増える)。
4. 新しい公演は、これまでどおり追加する。掲載の依頼フォームにも「出演する神楽団と演目」の欄がある。

> 演目の表記の違いをまとめるときは、`scripts/lib/lineup.mjs` の `PROGRAM_ALIASES` に足す(別の演目を混ぜないよう、確かなものだけ)。

### 2. SNS に投稿する(1時間)

- **木曜か金曜**: `/weekend/hiroshima.html` を開き、下の「SNSで紹介する」で**画像を保存**して、**投稿の文をコピー**して投稿する。
  - X の文は、文字数に収まるように自動で作り、リンクにどの投稿から来たかの印(utm)が付いている。
  - Instagram の文は、本文のリンクを押せないため「プロフィールのリンクから」と案内している。プロフィールのリンクは `https://kagurameguri.jp/weekend/hiroshima.html` にしておく。
- **公演の前日**: 神楽団ページか開催ページを、ひとこと添えて紹介する(#広島神楽 と、神楽団の名前)。
- **写真・動画の募集**: 募集の投稿を固定表示にして、ときどき呼びかける(main に取り込んでから)。
- ファンの投稿に返信するときは、宣伝のくり返しにならないようにする。

### 3. 数字を見る(0.5時間)

- Search Console: `/troupe/`・`/program/`・`/pref/広島県.html`・`/weekend/hiroshima.html` の表示回数・クリック。「○○神楽団」の検索で表示が出ているか。
- GA4: `utm_source=x` / `utm_campaign=weekend_hiroshima` の流入。
- 比べ方: 始める前の28日間を基準にし、同じ長さで比べる。曜日・季節(秋〜冬は公演が多い)・掲載数の違いを添える。順位やアクセスの増加は保証しない。

## まだやっていないこと(次の候補)

- 神楽団ごとのカレンダー(推しの神楽団の公演だけが届く)。
- X の自動投稿(`post-x`)の広島優先。X の API の鍵を GitHub に登録してから。
- 広島の定期公演の網羅(いまは「ひろしま神楽定期公演」の1件)。
