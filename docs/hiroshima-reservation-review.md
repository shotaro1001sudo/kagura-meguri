# 広島の直近日程と予約表示

広島県ページは既存の年入りタイトルと月別一覧を維持し、冒頭に掲載済み開催予定の先頭3件と定期公演への導線を表示する。開催日は既存データとisUpcoming判定を使い、全公演の網羅や空席を保証しない。他県の冒頭構成は変更しない。

## 予約データ

reservationStatus: unknown / required / recommended / not_required。
reservationSameDay:true は当日受付が明示される場合だけ登録する。requiredとの矛盾は要確認として扱う。状態が未設定なら従来のreservation文字列を維持し、料金やbooking自由文から推測しない。
一覧カード・詳細表・検索用JSONはreservationLabelを共有する。bookingは詳しい受付方法として残す。既存checkedは全体の確認日なので上書きせず、予約の再確認日はreservationCheckedで記録する。

## 確認元（2026-10-25）

- 高千穂町観光協会 https://takachiho-kanko.info/kagura/information/ : ネット予約と当日受付を併用し、定員に達した場合は入場できない旨を案内。事前予約を推奨・当日受付ありとして表示し、予約必須とはしない。
- 高知県公式 https://yosakoi-kochi-bunkasai2026.pref.kochi.lg.jp/event.html?id=251 : 永渕百手・永渕神楽は事前申込不要。既存日時・料金は維持する。

## 検証と更新時の注意

npm test、npm run build、git diff --checkを実施する。tests/reservation.mjsでは状態未設定・不正値・矛盾・旧形式と、トップ/詳細/県一覧の表示整合を検証する。

2026-10-25収集分を含むmainで、広島の直近3件は11/3ひろしまね神楽デー、11/7大朝神楽競演大会、11/7キャンドルナイト。11/7の2件はデータ上どちらもtimeUnknownであり、同一ソートキーの場合は元データ順を維持する。開始時刻の前後を意味しない。11/15の公演は月別一覧に残る。保留状態の竹あかりイベントは出力しない。

既設Chromiumの1280px・390px・320pxで外部通信を遮断し、スクリーンショット、折返し、ページ幅、Tabフォーカス、定期見出しへのEnter操作を確認した。新しい長いキャンドルナイト名称も390pxで折返しとリンク先を確認。実機Safariや外部フォント読込後の表示は未確認。

日付地域検索は既存仕様で単発公演のみを扱う。「高千穂」の検索結果にある神楽まつりへ、毎晩の定期公演の予約情報を転用しない。広告・同意・計測・CSP・GASには変更を加えない。
