# 公演情報と宿探しの共通案内

## 範囲

公演詳細・定期公演詳細の既存宿枠に、既存データの日時・会場、公演情報への内部リンク、宿検索の指定条件を表示する。共通部品は `scripts/lib/stay-planning.mjs`。個別公演の手書き案内、交通時刻、帰宅可否、空室、未確認の予約先は追加しない。

定期公演は日付未指定のままとし、観覧日を決めてリンク先で宿泊日・人数を指定する案内を出す。日付付き公演は既存の開催日泊・大人2名の検索条件を明示する。宿泊を必須とはしない。会場・日時がなければ未確認と表示する。県・種類の一覧には公演固有の案内を出さない。
