## 実装と確認方針

data/events.json に3件だけ追加。既存89件は変更しない。prefecture は出演者の出身地でなく開催地「東京都」。手動レコードに source、checked、公式URL、説明、検証済み会場座標を記録する。data/sources.json と週次の22件保留／深野の reviewHolds は変更せず、収集や承認コマンドを実行しない。

既存 sessions を検索・地図の軽量データへ渡し、検索結果と地図ポップアップにも開始時刻を表示。終了不明の複数回公演が初回から3時間で一覧から消えないよう、一覧掲載期限の既存3時間猶予は最終回の開始を基準にする。この計算値を end や Event.endDate に出力しない。Googleカレンダー／ICSは初回のみの仮登録であることと3回の開始を注意文に明記。

テストは3件・日付重複・未知料金／予約・構造化データ・東京一覧・実検索スクリプトの日付絞り込み・地図の座標と時刻・最終回前の掲載維持／翌日の終了扱いを検査。地図の自動検査ではLeafletをテストダブルに置き換え、生成されたポップアップと座標を検査する。
