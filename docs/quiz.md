# 神楽の好み診断（2026-10-26 改訂案）

`/quiz.html`。実行時AIや外部APIを使わず、ブラウザ内のメモリで判定する。回答・条件・得点・結果は保存/送信しない。性格・適性・相性の確率を判定するものではない。

## 質問と編集ルール

`scripts/lib/quiz.mjs` の質問定義が順序・選択肢・表示件数の共通元。好み7問（最初の注目、動き、場面、物語の楽しみ方、細部、案内希望、観覧後の気持ち）と任意条件3問（都道府県、日程、観覧時間）。すべて不明を選べる。案内希望は結果の補足だけに使い、順位を変えない。条件も順位に加えない。

各採点質問は合計1点。複数特徴の選択肢は均等に分配する。「分からない」は0点。推薦候補は既存の12種類で、複数の特徴を持てる。`traditions.evidence` の各特徴は `data/kagura-info.json` の出典付き本文のフィールドへ結び付ける。フィールド不在・空・未知の特徴ならビルドを停止する。既存の出典内容を新たに公式サイトで再監査したことを意味しない。

各種類で根拠のある特徴に回答点を加算し、最大3種類を表示。同点は定義の掲載順で安定させ、同点がある旨を表示する。関連する特徴が多い種類は得点を得やすく、全神楽を網羅した公平性や統計的妥当性は未検証。根拠のない特徴を補完せず、説明可能性を優先した編集モデル。点数や一致率は利用者へ示さない。全不明なら特定の種類を推薦しない。

推薦理由は実際の回答と一致する特徴、および根拠本文を最大2つ表示。「静かだから祭礼が向く」などの未裏付けの文化像は生成しない。広島神楽の系統差など原文の条件を保つ。実際の演目・特徴は団体や公演によって異なり、特定演目の上演は保証しない。

## 公演の条件

公開済み掲載データのうち推薦種類と県が一致し、指定日/今月/来月の期間に開催日が重なる公演を日付・ID順で最大6件表示。全国/未指定は絞らない。全不明の場合も対象12種類の掲載範囲に限られることを明示する。

日本時間で再評価する。終了時刻ありは終了まで、終了なしは既存サイト同様に開始後3時間、時刻不明は終了日（なければ開始日）の当日まで候補に残す。これらは掲載期限であり、実際に開催中と保証するものではない。日またぎも期間の重なりで扱う。

時間の希望は候補を除外しない。正確な必要観覧時間や途中入退場は不明なため、同日の開始/終了がある場合のみ掲載時間枠を示す。2時間/4時間は質問に明示した比較目安。時刻不明・終了なし・複数回・複数日は所要時間要確認。定期公演は地域と掲載期限のみ確認した別の参考枠で、希望日の開催や時間への適合を主張しない。該当なしでもカレンダーへ進める。

## 入口

`/quiz.html`、日本語フッターの手動リンク、および公演検索/一覧/詳細の小型モデルレス案内。英語、フォーム、規約類、診断自体には自動案内を置かない。

PCは30秒以上閲覧後のポインター上端退出。スマホは30秒・本文半分以上閲覧・上方向200pxスクロールを代替にする。真の退出検知ではない。画面外や非表示タブでは発火させない。フォーム入力中・他のモーダル表示中は抑制する。

同一タブのsessionStorageに表示済みフラグだけを保存し、1セッション1回。保存不可なら自動表示しない。Escape/閉じるとフォーカスを戻す。`beforeunload`・履歴追加・戻る横取り・外部リンクのクリック遮断は使用しない。モーダルとして本文をロックしない。

## 画面・検証

全問で明示的な「次へ」を押す。選択だけの自動遷移をやめ、タッチ/キーボードで同じ操作にする。前へ戻って修正でき、やり直しで回答・条件を消去する。進捗と件数は質問配列から算出。地域はネイティブselect、指定日はdate入力。非表示フォームの二重送信は無視する。

単体/生成DOM検証: 全不明・同点・根拠対応・条件の採点分離・不正日付・月末/年末/うるう年・開催中/日またぎ/時刻不明・0件・再集計/戻る/やり直し・同意/自己除外・個別情報非送信。実ブラウザの表示/キーボード検証は別途記録し、本番確認と区別する。

## 計測と受入

既存GA4の同意/自己除外許可後だけ、quiz_start/quiz_complete/quiz_event_click/quiz_search_clickを送る。個々の回答、点数、結果軸は送らない。完了率や送客効果はGoogle受信確認と母数が必要で、実装・CI・公開だけでは成果を断言しない。

PC1366pxとスマホ375/390/430px明暗の表示・完走・戻る・変更・やり直し・同点・0件・案内条件・1回抑制・閉じる/フォーカス復帰を確認する。本番実操作はローカルQAと区別する。追加サービス/有料API/購入なし。
